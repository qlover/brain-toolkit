设计说明

      
测试台让开发者用自己应用的真实参数，在站内把授权码流程走一遍，不会跳到外部 redirect_uri。背景用「安静版」，每一步是一张卡片，从上到下推进。


      
构成

      
    
        
  • 页头：logo + 竖线 +「测试台」，导航「控制台 / 文档」，右侧头像 + 退出。
    • 
        
  • 当前账号：页面本来就要求登录，所以原来的「1. 登录会话」步骤改成顶部一条账号信息，步骤从 5 步减为 4 步。
    • 
        
  • 1 选择客户端：客户端、redirect_uri 两个下划线下拉框；scope 用芯片多选；state 带「随机」；PKCE 小卡——公共客户端固定开启，机密客户端可用开关选择测试。
    • 
        
  • 2 授权确认：参数校验通过后显示授权 URL（可复制）和一张迷你授权卡，按钮「模拟拒绝 / 模拟允许」。
    • 
        
  • 3 换取令牌：展示回调得到的 code / state；机密客户端填 client_secret，公共客户端提示会自动提交 code_verifier。
    • 
        
  • 4 用户信息：展示 token 响应，按钮请求 userinfo，成功后显示结果和「流程完成」。
    • 
        
  • 步骤状态：已完成的步骤折叠成一行摘要（绿色对勾，可「修改」重新展开）；当前步骤展开，编号是品牌渐变；后面的步骤变淡锁定。
    • 
        
  • 错误：任何一步失败，顶部出现红色提示条，可关闭；错误文案需要翻译成中文（原来是英文硬编码）。
    •

设计说明

首页沿用登录页的视觉，把圆盘 + 漂浮白球作为首屏背景，下面的内容区只用近白色卡片，不再加背景装饰，避免喧宾夺主。

构成

  • 页头：logo + 文档 / 关于；右侧 GitHub、主题、语言，未登录显示黑色「登录」胶囊，登录后显示「控制台」+ 头像。
  • 首屏：浅灰胶囊「OAuth 2.0 授权服务器」，60px 细体大标题，第二行「中间层」用紫→蓝渐变文字；两个按钮「开始使用」（黑色胶囊 + 箭头）和「阅读文档」（描边胶囊）。
  • 特性：三张近白色卡片，渐变圆形图标 + 标题 + 一行说明。手机端改成单列。
  • 主要端点：白色代码卡片，列出 authorize / token / userinfo / revoke 四个端点，方法名用点缀蓝。
  • 行动号召：一张卡片「准备好开始了吗？」+「前往控制台」。

状态

  • 未登录 / 已登录：只影响页头右侧按钮。

设计说明

沿用登录页的整套视觉：圆盘 + 漂浮白球背景、近白色毛玻璃卡片、细体标题、黑色胶囊主按钮。卡片比登录页略宽（460px），信息从上到下按「谁在请求 → 以谁的身份 → 要什么权限 → 是否信任 → 决定」排列。

构成

  • 应用信息：白色小卡，应用 Logo（没有 Logo 时用首字母渐变头像）+ 名称 + 描述 + 蓝色「OAuth 2.0」胶囊，和登录页「授权跳转」状态的小卡是同一个组件。
  • 当前授权账号：小头像 + 邮箱 + 打码手机号，右侧蓝色文字「不是你？切换账号」，点击回到登录页。
  • 请求的权限：蓝色圆形对勾列表；右上角「详情」展开一条浅灰提示「该应用不会获取您的密码」。
  • 信任此应用：渐变开关，对应现有的按设备记住授权（90 天）；问号图标悬停显示说明。
  • 按钮：左「拒绝」（描边胶囊），右「同意授权」（黑色胶囊 + 箭头），等宽并排。

状态

  • 加载中：点同意后按钮显示转圈并禁用。
  • 拒绝确认：点拒绝弹出确认框，确认后带 error=access_denied 回到应用。
  • 参数无效：client_id 无效、回调地址未注册、scope 超范围等，整张卡换成错误卡片（红色提示条 + 返回按钮），不展示授权表单。

设计说明

后台沿用 Brain 的页头（logo + 竖线 +「管理后台」），不再用原来那套独立的顶栏。左侧一列侧边导航，当前项是白色小卡 + 紫色图标；内容区全部是近白色卡片，表格没有竖线，只用浅色横线分隔。

构成

  • 侧边导航：概览、用户管理、请求日志、站点设置；「用户管理」「站点设置」只有管理员可见（带「管理员」小标签）。手机端变成顶部横向滚动的标签。
  • 概览：四张数字卡（注册用户、OAuth 应用、今日授权、今日失败率）+ 近 7 天授权柱状图 + 最近请求列表（点「查看全部」跳到请求日志）。普通用户看不到「注册用户」，其余数字只统计自己的应用。
  • 用户管理：搜索（邮箱 / 手机号 / ID）+ 角色筛选芯片 + 刷新；表格列：用户（头像 + 名称 + 邮箱）、角色、登录方式、应用数、注册时间、最近登录、操作。点行打开用户详情，可以「设为管理员 / 取消管理员」，需要二次确认。
  • 请求日志：搜索（请求 ID / 路径 / IP）+ 类别下拉 + 成功 / 失败芯片 + 刷新；表格列：时间、请求（方法 + 路径）、事件（类别 · 类型）、结果（状态码胶囊，绿 / 红）、耗时、IP、登录方式。点行打开详情，请求 ID 可复制，失败时显示错误码和信息。分页：范围 + 每页条数 + 页码。
  • 站点设置：「API 与 CORS」卡片，规则来源胶囊（数据库 / 默认）；每条规则是一张小卡：来源 Origin、API 路径（都可用 * 芯片表示任意）、方法芯片多选（* 与其他互斥）、删除。底部「添加规则」「保存」。
  • 状态：列表有数据 / 空 / 加载中；设置有规则 / 空 / 校验错误（Origin 下划线变红 + 红字说明）；普通用户访问管理员页面显示「没有权限」。

已确认的决定

  • 已确认 概览和用户管理现在是占位页，数字卡、柱状图、用户列表都需要新增接口。
  • 已确认 用户来自 Brain，不在这里创建 / 删除用户，也不改密码；后台只看信息和调整角色。原来 i18n 里的「创建用户 / 密码」等文案可以删掉。
  • 已确认 请求日志新增的搜索和筛选需要接口支持；普通用户只能看到自己的日志。
  • 已确认 后台改用 Brain 页头后，原来的侧栏折叠按钮不再需要。

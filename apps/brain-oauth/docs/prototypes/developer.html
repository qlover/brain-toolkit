设计说明

控制台是信息密集页面，背景换成「安静版」：圆盘缩小移到右上角，只留三颗小球，内容区全部用近白色卡片承载。整体仍是细体标题 + 黑色胶囊主按钮 + 下划线输入框。

构成

  • 页头：logo + 竖线 +「开发者控制台」，导航「测试台 / 文档」；右侧 GitHub、主题、语言、头像、退出。
  • 应用卡片：头像 + 名称 +「已启用」绿色胶囊 + 客户端类型紫色胶囊；右侧文字按钮「编辑 / 重置密钥 / 删除」（公共客户端没有密钥，不显示重置）。下方两列信息：Client ID（带复制）、重定向 URI（每个一枚代码块）、创建时间。
  • 创建应用：弹窗内全部是下划线输入框；客户端类型用两张白色选择卡（机密客户端 / 公共客户端 PKCE），创建后不可更改。
  • 凭据弹窗：创建成功或重置密钥后弹出，Client Secret 只显示一次，下方橙色提示；公共客户端没有 secret，改为蓝色说明。
  • 编辑应用：客户端类型只读显示；左下角「重置密钥」「删除应用」，右下角「取消 / 保存修改」。
  • 危险操作：重置密钥、删除应用都弹出二次确认，确认按钮为红色胶囊。

状态

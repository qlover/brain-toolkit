目录结构

  • assets/brain.css：共享样式——主题变量、圆盘和漂浮白球背景（完整版 / 安静版）、卡片、下划线输入框、标签切换、开关、按钮、代码块、提示条、弹窗、轻提示。
  • assets/brain.js：共享脚本——顶部工具栏、主题 / 语言 / 视图切换（跨页面记住）、多语言、logo 和图标注入。页面只需要调用 BrainProto.init() 并写自己的结构和文案。
  • 每个页面底部的「设计说明」记录构成、状态和待确认事项；确认后在这里把状态改成「已确认」。

约定

  • 直接用浏览器静态打开即可，不需要启动服务。
  • 新增页面：复制一个现有页面，替换 main 里的结构和 i18n 文案，再在本页加一张卡片。

PAM 登录页 · Brain 登录按钮方案

参考 brain-oauth 原型（apps/brain-oauth/docs/prototypes/login.html）：黑色胶囊主按钮 + 箭头，紫蓝只做点缀。

说明

  • Brain 视觉要点（取自 brain-oauth 原型设计说明）：冷调浅灰、白色哑光立体球、近白色无边框卡片、细体字；主按钮是黑色胶囊 + 箭头，暗色主题反转为白色；紫 #7B2FE0 → 蓝 #5B8DEF 渐变只用于下划线、选中短线等点缀。
  • 方案 A 与 GitHub 的反色按钮会撞色，所以 A 里 GitHub 改为描边按钮；其他方案 GitHub 保持反色。
  • 「发送验证码」保持 PAM 主题紫实心，作为表单主操作，第三方按钮都不能和它长得一样。
  • 悬停按钮可看交互：A / B 箭头轻推，B 底部出现紫蓝渐变下划线，C 底色轻微泛蓝。

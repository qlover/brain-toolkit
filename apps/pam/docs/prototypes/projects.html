添加环境（名称 + 访问地址，变量可稍后在「环境变量」里配置）

设计说明 · 项目列表

  • 布局与现有页面一致：卡片模式 = 首页截图封面 + 图标 / 名称 + 描述 + 环境直达；列表模式 = 一行一个项目。
  • 没有首页截图的卡片显示生成的占位封面（按 slug 取色的渐变 + 仓库图标 + 项目名），保证同一行卡片结构一致、不会因为旁边有截图而被拉出大片空白；没有任何入口时「快速入口」显示「暂无」，卡片底部对齐。
  • 卡片头部压成两行：名称；「分类 · 技术栈 · 更新时间」（当年省略年份，不折行，超长截断）。技术栈不再单独占一行，拥有者 ID 从卡片去掉（列表模式和详情页里有），避免头像下方和技术栈右侧留白。
  • 描述改为 Markdown 后，两种模式都只显示第一段正文（去掉 Markdown 语法）：卡片最多两行，列表一行。标题、列表、备注等只在详情页完整显示。
  • 链接：描述里写成 [标题](地址) 的链接按域名识别类型（Figma → 设计、Jira → 需求、飞书 / Apifox 等 → 文档），用虚线边框和环境区分。 卡片把「环境直达」改为一行「快速入口」：环境在前、链接（图标 + 标题）在后，最多显示 5 个，剩下的收进末尾「+N」按钮，点开就是快速访问菜单（和列表模式同一个）。
  • 代码仓库地址不算链接：GitHub / GitLab / Gitee / Bitbucket 的地址已经可以通过头像（repo_url）打开，提取时直接跳过，不重复显示。
  • 列表模式按屏幕宽度逐级显示（点行进入项目详情；入口都是一次点击直达）：
    · 手机：图标 + 名称 + 一行摘要；底部一行快速链接（环境在前、链接在后，最多 4 个，超出可横向滑动）。
    · ≥768px：快速链接移到行右侧——2 个环境 + 2 个链接图标。
    · ≥1024px：名称后面跟一行弱化的「分类 · 技术栈 · 更新时间」（不做成表格列，避免整页像表格）。
    · ≥1280px：环境增加到 3 个，链接改为「图标 + 标题」。
  • 快速访问：行最右侧的按钮（数字 = 环境 + 链接总数）列出该项目全部入口，每项显示名称和域名，点击直接打开；末尾是「查看项目详情」。 小屏从底部弹出面板（大点击区域、点遮罩关闭），桌面端是按钮下方的下拉菜单（点外部或 Esc 关闭）。
  • 移动端（缩小窗口或用浏览器设备模式查看）：工具栏搜索框独占一行，按钮只显示图标；分类标签横向滚动；卡片单列；页头导航收进菜单按钮。
  • 列表页不加载 Markdown 渲染器：摘要和链接用一个几十行的函数提取。列表接口可只返回描述前几百字 + 提取好的链接，避免描述变长后列表响应变大。
  • 「新增资产」弹窗可以直接填完整描述：输入框自动长高（约 10 行后滚动），「预览」首次点击才加载渲染器，右上角「展开」打开左右分栏的大编辑区。

列表「查看详情」交互（待选，列表模式顶部可切换）

  • A 抽屉（可钉住）：点行从右侧滑出详情，列表仍可见，↑ ↓ 切换、Esc 关闭；≥1280px 点图钉固定成右侧分栏（原「分栏」方案合并进来，偏好会记住）。 缺点：抽屉会盖住列表右侧的快速入口。
  • B 行内展开：点行在该行下方原地展开（左完整说明，右入口、信息、打开详情页），再点收起，同时只展开一行，↑ ↓ 切换。 不遮挡任何东西、上下文最完整；缺点：展开后下面的行被推下去，长说明会让列表变长。
  • C 详细列表：不加交互，换一种「详细」列表：每行带封面缩略图、两行摘要、全部入口，点行进详情页。 一眼看全、零学习成本；缺点：每屏能看的项目变少（约一半），说明只到摘要。也可以做成工具栏里「紧凑 / 详细」切换。
  • D 预览弹窗：点行弹出居中大窗，左侧完整说明、右侧封面 / 入口 / 信息，顶部上一个 / 下一个连续浏览。 阅读空间最大；缺点：遮住整个列表，看不到上下文。
  • E 展开卡片（iOS 风格）：类似 App Store「Today」卡片：点行，这一行从原位置平滑放大成详情卡（桌面居中；手机四周留出间隙、顶部多留一点，能看到背后的列表），顶部是封面大图 + 标题，往下是入口、说明、信息； 关闭（✕、点遮罩、Esc、返回手势，手机在顶部下拉）时卡片缩回原来那一行。手机端这个方案替代底部面板。 动效最有「打开」的感觉，用户清楚详情从哪来、回到哪去；缺点：动画实现稍复杂，需要处理好列表滚动和窗口尺寸变化。
  • 手机（<768px）A–D 统一用底部面板（E 在手机上是四周留间隙的大卡片）：点行先弹出约 60% 高度（快速入口排最前，其次说明、封面、信息）； 拖动顶部条上滑全屏、下滑收起 / 关闭；系统返回键 / 返回手势关闭面板而不是离开页面；顶部固定栏有上一个 / 下一个、打开详情页、关闭，按钮 40px 点击区域；面板打开时背景不滚动。
  • 各方案的详情内容是同一个组件（详情页「概览」也复用），Markdown 渲染器只在打开时加载。可以组合，例如「详细列表」作为视图切换 + 点行用抽屉。
